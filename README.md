# 사주 궁합 매칭 채팅 서비스

실시간 사주 궁합 분석을 통한 매칭 채팅 서비스입니다.

## 주요 기능

### 1. 사주 분석 시스템
- 생년월일시(양력) 입력을 통한 만세력 계산
- 사주 사주(년주, 월주, 일주, 시주) 산출
- 오행 점수 계산 (목, 화, 토, 금, 수)
- 용신 분석

### 2. 궁합 매칭 시스템
- **오행 보완**: 부족한 오행을 상대가 보완해주는 정도
- **용신 매칭**: 상대에게 자신의 용신이 얼마나 있는지
- **천을귀인**: 상대의 일지, 월지에 천을귀인이 있는 경우
- **일지 관계**: 동일, 육합, 삼합 관계
- **천간삼기**: 천간의 오행 매칭

### 3. 실시간 채팅
- Socket.io 기반 실시간 메시징
- 궁합 점수 표시
- 매칭 대기열 시스템

## 설치 및 실행

### 1. 의존성 설치
```bash
npm install
```

### 2. MySQL 데이터베이스 설정
```bash
# MySQL 서버 실행 후 데이터베이스 생성
mysql -u root -p < database/schema.sql
```

### 3. 환경변수 설정
`.env` 파일에서 데이터베이스 정보를 설정하세요:
```
DB_HOST=localhost
DB_USER=root
DB_PASSWORD=your_password
DB_NAME=saju_matching
```

### 4. 서버 실행
```bash
# 개발 모드
npm run dev

# 프로덕션 모드  
npm start
```

### 5. 웹 브라우저에서 접속
```
http://localhost:3000
```

## 사주 계산 알고리즘

### 만세력 계산
- 기준년도(1924년 갑자년)를 기준으로 60갑자 순환 계산
- 년주, 월주, 일주, 시주 산출

### 오행 점수 계산
각 간지의 오행 속성에 따라 점수 부여:
- 목(木): 갑을인묘
- 화(火): 병정사오  
- 토(土): 무기진미술축
- 금(金): 경신신유
- 수(水): 임계자해

### 궁합 점수 계산
1. **오행 보완 점수**: 상대의 강한 오행이 내 부족한 오행을 보완하는 정도
2. **용신 점수**: 상대가 내 용신을 많이 가진 정도
3. **천을귀인 점수**: 천을귀인 관계 시 가산점
4. **일지 관계 점수**: 육합(20점), 삼합(25점), 동일(15점)
5. **천간삼기 점수**: 같은 오행 천간 시 가산점

## 기술 스택

- **Backend**: Node.js, Express.js
- **Database**: MySQL
- **Real-time**: Socket.io
- **Frontend**: Vanilla JavaScript, CSS3
- **Libraries**: moment.js, mysql2

## 매칭 플로우

1. 사용자 생년월일시, 성별 입력
2. 사주 계산 및 결과 표시
3. 매칭 시작 요청
4. 기존 대기자 중 궁합 매칭 (30점 이상)
5. 매칭 성공 시 채팅방 생성, 실패 시 대기열 추가
6. 새 사용자 연결 시 자동 매칭 재시도
